§ The lab

Eight tools, all client-side

Every tool runs in your browser. Inputs are kept in localStorage so you can come back to a model. Nothing is sent to any server unless you explicitly use the optional Ask Tutor field, which only forwards the question text.

A note on privacy

All eight tools are pure HTML/JS that run in this tab. Inputs and outputs are persisted in localStorage on your machine and can be cleared from each tool's toolbar. There is no analytics, no telemetry, and no remote logging. The optional Ask-Tutor field — when present — sends only the literal question you type, never your model inputs.
