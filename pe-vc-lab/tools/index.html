The PE/VC Operator's Lab Cover Chapters Tools
The Lab · 8 tools · 100% client-side

Open the lab

Each tool is a single static page. Inputs persist locally, exports are downloads, and there is no analytics. Pick a tool — or run the chapters first, then come back.

T1
Case Study Analyzer

A guided checklist across company, market, unit economics, risks, and thesis. Saves locally; exports to Markdown.
T2
LBO / VC Model

Editable assumptions; computes IRR, MOIC, pre/post-money, dilution and a small sensitivity grid.
T3
Balance-sheet checker

Enter a few rows; verifies the accounting identity and runs eight red-flag heuristics.
T4
Cap table & waterfall

Founders, options, multiple priced rounds, and a 1× / participating / stacked exit waterfall.
T5
IC memo builder

Structures raw notes into the seven-block memo from Ch. 05; copy as Markdown.
T6
Diligence red flags

A scored checklist of patterns that have killed deals at the table; outputs a verdict band.
T7
Sector thesis canvas

Six-field canvases for AI, deep-tech, and space; loadable templates plus blank.
T8
Capability drills

Beginner / intermediate / expert drills mapped to each tool, with self-assessment.

Channeling the lab

The tools are designed to be used in order. Read a real case (10-K, S-1, founder deck), open the Case Study Analyzer, then move to the LBO/VC model and the balance-sheet checker. The IC memo consolidates everything into a one-page output.
